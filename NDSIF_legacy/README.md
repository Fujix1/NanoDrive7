このディレクトリは、正式v1の策定草案を整理する前の文書版0.37を保存する試作版・履歴資料です。NDSIFはまだb版であり、正式v1は成立していません。

- [b版APIと0.37の拡張案](NDSIF_API.md)
- [旧ホスト手順](NDSIF_HOST_GUIDE.md)

保存文書中の「v1」は当時の仮称であり、正式v1の公開を示すものではありません。「現行」「実装済み」は保存時点のNanoDrive8のb版実装を指します。0.37で追加した `04` / `05`、旧論理チップID、`59` kind=4 は未実装の拡張案で、現在の正式v1草案では採用しません。b版APIと正式v1草案の同じ数値を相互に読み替えないでください。

正式v1の策定草案はリポジトリ直下の [基本仕様](../NDSIF.md) / [API仕様](../NDSIF_API.md) / [ホスト手順](../NDSIF_HOST_GUIDE.md) です。この文書更新は、b版ファームウェアやcodecを変更するものではありません。
